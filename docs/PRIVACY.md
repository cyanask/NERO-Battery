# 隐私说明

NERO Battery 在本机采集电池电量、容量、循环次数、温度、供电状态和充电开关等电源信息，用于展示和控制。设置、定时任务、历史图表及恢复状态保存在本机的应用支持目录，不通过本应用上传。

用户主动运行应用能耗采样时，会读取本机进程名称、CPU 等资源数据，用于近似分析。它不等于硬件直接测量每个应用的瓦数。安装预检短暂读取进程命令路径以发现冲突的电池控制器，不保留完整进程清单。

没有统计 SDK、崩溃上传、账号、云同步、网络监听或自动更新。系统自身、其他软件和备份服务的数据处理不由本应用控制。用户自行提交日志或截图时，应先检查是否含进程名称、用户路径或私人设置。

卸载默认保留设置和历史，便于恢复；不会清空其他软件的数据。二进制及源码发布物不包含开发机的充电记录、信任策略、账户资料或性能采样日志。
