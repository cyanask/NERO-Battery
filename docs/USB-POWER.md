# USB 外设输出功率

1.1.0 沿用 AlDente Pro 可验证的 USB 输出数据路径：读取 IORegistry 的 `AppleSmartBattery.PowerOutDetails`，取各条目 `Watts` 值并除以 1000 转为 W。它是系统报告的端口输出，不是设备申报电流、PD 协商上限或由总耗电推算出的分配结果。

该协议由官方 AlDente 1.40.1 镜像的只读静态检查确认，镜像 SHA256 为 `cbe3f47f1b08b9de5760caf46b4965a6ec80b1ff8b5f043a7e83b952b006ca23`。检查没有安装、启动或激活 AlDente，也不向本软件加入其代码、二进制或依赖。这里复用的是数据接口、字段及单位事实，不声称逐行复现其私有实现。

AlDente 的处理另有 `PDPowermW` 后备字段。该字段未在本机完成含义校验，NERO 不将它作为实测功率，不以它填补 `Watts` 缺失。公开同类实现也可见 [macpow 的读取代码](https://github.com/k06a/macpow/blob/main/src/battery.rs)。AlDente 官方只承诺在 Mac 报告数据时提供 USB 输出，未保证每个设备都有独立功率计，见 [官方功能说明](https://apphousekitchen.com/aldente-overview/features/)。

## 本机核实结果

在 M4 / Mac16,12、macOS 26.6.2 上识别到两个 USB-C 系统接口，编号为 1、2。当前 `PowerOutDetails` 属性缺失，端口控制器也没有可确认的实时输出功率读数；可见的供电能力、最大电流及协商上限没有计入输出。

因此，本机总览显示 USB 输出“—”，两个端口显示“未报告”。这不代表外设耗电为 0 W，也不能据此断言该机型在所有连接状态下都永远不报告。没有插拔、重置端口或进行充放电控制来制造读数。

## 数据边界

- 空报告、属性缺失、类型错误及缺少功率字段均保持未知，不补零。
- 合计只覆盖系统报告的完整输出记录。任一条目缺失 `Watts` 时，总计保持未知；仍可展示其他有报告的条目。
- 输出记录的系统索引与接口清单分开展示，不猜测它对应哪侧接口或哪台设备，不分摊扩展坞下设备的功率。
- 当前只有“无报告”分支在本机实机核实；有正值的路径尚缺提供该遥测的设备验收，不以合成数据代替。
- 只在总览可见时采集，或由用户显式运行 `--usb-power` 做一次只读诊断。关闭窗口后不新增后台轮询，不申请额外权限，不上传数据。
