# 安全边界

- 不修改 SIP、Gatekeeper 或系统启动安全设置；不要求关闭 FileVault，不安装内核扩展。
- 安装和前端更新保留、传递下载文件的 `com.apple.quarantine` 标记，不通过复制过程移除首次运行确认。
- 控制后台使用系统 IOKit/SMC 及 NSXPC。本机 HTTP 路由仅用作内部分发，不绑定 TCP/UDP 监听端口。
- XPC 使用内核提供的调用方身份，固定授权 UID、客户端 CDHash 和后台 CDHash；安装器检查 root 所有权、目录祖先、写权限、符号链接及 ACL。客户端不接受任意 shell 命令。
- 前端可由用户独立更新；后台和客户端必须通过管理员授权更新。校验策略不由连接方自动学习，也不把前端可写目录列为受保护代码路径。
- 冲突检查仅在接管前执行。不要在 NERO 已接管时重新启动其他充电控制器；运行中不会持续扫描或阻止其他软件。
- 温度缺失、睡眠及流程中断等情况按现有安全状态机处理。热保护和校准不是医疗、消防或硬件保修保证，不能修复电池物理老化。

目前为 ad-hoc 签名，代码哈希提供本地完整性约束，不提供可信发布者认证。第三方应校验来自可信渠道的 SHA256，并通过 macOS 正常的单应用确认运行。若无法运行，不应以关闭系统保护的方式绕过。

此版本尚未经过独立安全审计和多机型安装验收。请勿在问题报告中公开管理员密码、私人设置、完整进程清单或恢复目录。出现异常时先在应用中取消主动流程并恢复电源；无法确认状态时保留现场并停止试用。
