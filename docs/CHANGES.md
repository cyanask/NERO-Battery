# 1.0.0

- 从源码独立构建 ARM64 正式优化版本，不复制已安装 App。
- 增加可迁移的账户识别、发布清单、SMC 能力预检及安装/升级/卸载工具。
- 保留前端独立更新、固定客户端、XPC 的 UID/CDHash 校验和空闲客户端退出机制。
- 后台受保护组件更新失败时恢复旧文件；卸载前恢复并读回电源开关。
- 停用旧的单机迁移和 `.pkg` 入口；不包含证书申请、公证或系统安全保护降级步骤。
- 复制程序时保留 Gatekeeper 隔离标记，避免绕过正常首次运行确认。
- 增加完整源码、固定 vendor 依赖、隐私与安全说明、支持范围和试用限制。
- 未改变日常限充策略；未新增上传、常驻冲突扫描、自动放电或自动更新。
- 原生快捷指令仍不可用；不宣称完成多机型、实际放电或校准验收。
