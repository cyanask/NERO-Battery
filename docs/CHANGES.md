# 1.2.1

- 清理暂不可用的原生快捷指令定义、系统注册声明及界面入口。侧栏和页面标题使用“定时任务”。
- 新前端重新签名，可通过 `Update-GUI.command` 原位更新。沿用已有充电后台和固定控制客户端。

# 1.2.0

- USB 输出优先读取 SMC 输出电压、电流，明确标注“电压 × 电流换算”，不使用协商额度或功率差估算。
- 通过通道与控制器标识精确匹配 USB-C 端口，排除 MagSafe；标识只在内存使用。
- 前端 USB 读取核验 IOKit 返回值、输出结构大小、SMC result/status、字段类型与长度；失败保持未知，不补零。
- 部分端口不可用时合计保持未知；全部 SMC 读数不可用时才退回系统报告，并标明来源。不同来源不混合合计。
- 沿用总览可见时的刷新，关窗不新增采集。后台、固定控制客户端及授权策略不变，支持无需管理员认证的前端更新。

# 1.1.0

- 总览新增 USB 输出可用性及系统报告功率展示，支持只读 `--usb-power` 诊断。
- 不用协商功率、申报电流或功率差伪造实测；缺失、部分缺失和空报告均保持未知。
- 合计仅覆盖系统提供的完整输出记录，端口索引不强行映射为具体设备。
- 仅在总览可见时读取，不增加后台轮询、权限或网络连接。
- 本机当前没有可确认的 USB 总输出或逐端口实时读数；正值分支尚无本机实测。

# 1.0.0

- 从源码独立构建 ARM64 正式优化版本，不复制已安装 App。
- 增加可迁移的账户识别、发布清单、SMC 能力预检及安装/升级/卸载工具。
- 保留前端独立更新、固定客户端、XPC 的 UID/CDHash 校验和空闲客户端退出机制。
- 后台受保护组件更新失败时恢复旧文件；卸载前恢复并读回电源开关。
- 停用旧的单机迁移和 `.pkg` 入口；不包含证书申请、公证或系统安全保护降级步骤。
- 复制程序时保留 Gatekeeper 隔离标记，避免绕过正常首次运行确认。
- 增加完整源码、固定 vendor 依赖、隐私与安全说明、支持范围和试用限制。
- 未改变日常限充策略；未新增上传、常驻冲突扫描、自动放电或自动更新。
- 原生快捷指令仍不可用；不宣称完成多机型、实际放电或校准验收。
